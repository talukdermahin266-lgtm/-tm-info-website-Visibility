## Deploy on Netlify using Android
1. Download and extract this ZIP on your phone, or upload the ZIP to a file manager that can extract it.
2. Ensure `index.html` is directly inside the publish folder, together with `assets/` and `netlify.toml`.
3. Open https://app.netlify.com/ and sign in.
4. Select the existing `tm-info` site, then open Deploys.
5. Use the current manual deploy / drag-and-drop upload option to upload the extracted publish folder (the folder containing `index.html`), not a ZIP nested inside another folder.
6. Wait until deployment succeeds. Open https://tm-info.netlify.app/ and test Projects, Articles, menu, theme and language controls.
